# Release validation and immutable images

CI runs backend verification (including PostgreSQL migration tests), workspace
boundary lint, frontend unit tests and strict build, desktop tests, a Chromium
workspace smoke test, operations tests, and shell checks. The `Required checks`
job fails if any prerequisite fails, is cancelled, or is skipped.

Configure the main-branch protection rule to require **Required checks**. A
workflow file cannot configure this GitHub repository setting. Image publishing
already requires the CI workflow on main to finish successfully and checks out
that exact successful commit; failed CI cannot publish a release image.

Frontend lint currently has 97 pre-existing errors/warnings. `lint:ci` compares
findings by file, rule, severity, message, and occurrence count against
`frontend/eslint-baseline.json`; any new finding fails. `npm run lint` continues to
report all findings. Reduce the baseline as those issues are fixed; do not
regenerate it to accept new violations.

The Docker workflow builds both `linux/amd64` and `linux/arm64`, publishes
commit-tagged images, generates BuildKit SBOM/provenance attestations, and signs
and verifies the image digests with Cosign. The `image-frontend` and
`image-backend` artifacts contain exact deployable references. The redundant
simplified Docker workflow has been removed. Release Please also waits for CI;
release assets are built only when the release tag matches the verified commit.
Its image archives use the OCI exporter, which supports both architectures.

Frontend builds use the root workspace lockfile and `npm ci`; CI and Docker use
the Node version in `.node-version` (also pinned in the Dockerfile). Run
`docker build -f frontend/Dockerfile .` from the repository root. The frontend
reads its OIDC issuer/client ID from `runtime-config.js`, generated by the
container entrypoint using `MODULO_OIDC_ISSUER` and `MODULO_OIDC_CLIENT_ID`.
The file is not cached by nginx or the service worker. Authentication bypass is
restricted to Vite development builds.

The browser smoke test runs the real workspace with a mocked API and development
login bypass. It does not claim to validate live authentication. The OCI release
gate separately verifies OIDC discovery, rejection of anonymous note requests,
authenticated note creation, exact read-back, deletion, and absence after deletion.

See `deploy/oci/README.md` for release, rollback, and backup commands.
