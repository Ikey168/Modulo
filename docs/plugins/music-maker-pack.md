# Music Maker plugin pack

The Music Maker pack provides an independent music-production and practice system while sharing Modulo's Planner and Calendar day blocks.

| Plugin | Scope |
| --- | --- |
| Track Lab | Tracks, EPs, albums, live/DJ sets, modular patches, production stages, BPM/key, collaborators, releases, next actions, and definitions of done |
| Instrument Practice | Guitar, piano, theory, ear training, repertoire, rehearsals, tempo progression, and block-aware sessions |
| Music Library & Studio | Samples, presets, patches, gear, production references, repertoire, setlists, signal chains, sources, licenses, and project relationships |
| Music Dashboard | Active production, weekly practice, missing next actions, releases, gear, patches, and reference-library health |

The pack also installs Hobby Stack, Planner, Calendar, Media Library, Education Core, Home Inventory, and Personal CRM. Those plugins keep ownership of hobby experiments, scheduling, ordinary listening, formal study, insured equipment, and people respectively.

External REAPER, MusicBrainz, Discogs, streaming-history, Git, or file-indexing connections are intentionally left as optional future adapters.
